Description

**Problem: Sybil Attacks ($3.5T Risk)** DePIN networks are drained by "Ghost Fleets"—fake identities that exploit rewards without doing work. **Solution: State-Locked Protocol (SLP)** SLP is a "Proof of Physics" layer that cryptographically binds hardware state to the Solana blockchain. • TEE Enclaves: We execute logic inside ARM TrustZone, isolated from the Android OS. • Hardware Locking: If a device context-switches, the TEE signature fails, and the on-chain state locks instantly. • Anchored Trust: Rewards are only minted when a valid "Kinetic Proof" is verified by our Anchor program. **The Agentic Workflow** • Architect (Human): Designed game theory & security model. • Engineer (Agent): Built 90% of the Rust/TS code autonomously using Antigravity IDE. **Why Solana?** SLP requires 400ms block times to verify "Proof of Physics" in real-time.
