# SLP Validator (State-Locked Protocol Agent)

> **Hardware-Enforced Agentic Autonomy on Solana**

This repository contains the reference implementation for the **SLP Validator**, a Solana Smart Contract built with [Anchor](https://www.anchor-lang.com/). It serves as the on-chain enforcement layer for the State-Locked Protocol ($SLP), verifying cryptographic proofs generated by trusted hardware devices (drones, robots, edge devices).

## 🚀 Features

- **Device Registration**: On-chain identity management for hardware fleets using PDAs (Program Derived Addresses).
- **Proof of Kinetic Power (PoKP)**: Verifies physical interactions to unlock state changes.
  - `GpsGeofence`: Validates location confirmation.
  - `NfcHandshake`: Validates physical proximity/interaction.
  - `Vibration`: Validates kinetic impact or movement.
- **Replay Protection**: Enforces monotonic counters to preventing proof reuse or tampering.
- **Agentic Decision Making**: Smart contract logic that autonomously approves or blocks transactions based on hardware signal validity.

### 🛡️ Security Paradigm: Proof of Physics vs. Proof of Personhood

While standard Proof of Personhood (PoP) focuses on "Who" is behind a screen using biometrics, SLP focuses on "What" is happening in the physical world.

**The Problem**: In DePIN, a single verified human can still use a server to spoof 10,000 "virtual" devices (Sybil Attack).

**The SLP Solution**: We enforce **Proof of Physics (PoPhys)**. By anchoring our verification logic in a hardware TEE (Trusted Execution Environment), we ensure that a transaction is only valid if the laws of physics were obeyed. If there is no kinetic signal (vibration, GPS movement), there is no state-lock release.

## 🛠️ Prerequisites

To build and run this project, you need a specific Solana/Rust toolchain configuration due to modern dependency requirements.

- **Solana CLI**: v1.18.26 (or newer)
- **Rust**: **v1.79.0+**
  - _Note_: If you are using Solana v1.18, you may need to manually install `platform-tools-v1.43` or aliased a newer Rust toolchain to satisfy dependencies like `indexmap` and `blake3`.
- **Anchor CLI**: v0.30.1
- **Node.js** & **Yarn**

## 📦 Installation

1. **Clone the repository**

   ```bash
   git clone https://github.com/johnGreetme/slp-solana-agent.git
   cd slp-solana-agent/slp_validator
   ```

   **⚠️ Important:** All commands below must be run from the `slp_validator` directory.

2. **Install Dependencies**

   ```bash
   npm install
   ```

3. **Build the Program**
   ```bash
   anchor build
   ```

## 🧪 Running Tests

We use a comprehensive TypeScript simulation suite to verify the agent's behavior.

1. **Start a Local Validator** (Optional, `anchor test` can handle this widely)

   ```bash
   solana-test-validator
   ```

2. **Run the Test Suite**
   ```bash
   anchor test
   ```
   _This will register a fleet of 5 drones, simulating GPS and Vibration triggers, and attempt a replay attack to verify security defenses._

## 🏗️ Architecture

- **PDA Scheme**: `["device-state", authority_key, hardware_id]`
- **State Account**: `DeviceState`
  - `authority`: Owner of the device.
  - `hardware_id`: Unique string identifier.
  - `reputation_score`: On-chain trust score.
  - `last_counter`: Replay protection mechanism.
