# SLP Dashboard

A Judge-Facing "Mission Control" interface for the State-Locked Protocol.

## Features

- **Visualizer**: See the "Zero-Allocation" state in action.
- **Simulation**: Trigger Valid vs. Invalid hardware proofs.
- **Logs**: Watch the mock validator verify TEE signatures.

## Quick Start

```bash
cd web
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the dashboard.
